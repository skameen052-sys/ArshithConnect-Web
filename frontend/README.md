# Arshith Connect — Employee Attendance & Administration Portal

Enterprise workforce management, daily attendance tracking, leave processing, and administration web application built with **React.js (v19)** and **Vite**.

Refer to the master [README.md](../README.md) in the project root for complete setup, module descriptions, service layer details, and future FastAPI backend integration guides.

### Quick Start
```bash
# 1. Install dependencies
npm install

# 2. Configure environment
# Copy .env.example to .env and ensure VITE_API_BASE_URL points to the backend (e.g. http://127.0.0.1:8000)
cp .env.example .env

# 3. Start development server
npm run dev

# 4. Run production build
npm run build
```
